# Casper Agentic Buildathon 2026 Official Rules Snapshot

Verified on 2026-06-06 from the DoraHacks buildathon page after browser access was available.

## Event

- Name: Casper Agentic Buildathon 2026 - Qualification Round
- Organizer: Casper Association
- Platform partner: DoraHacks
- Event partner: Istanbul Blockchain Week
- Format: Virtual, with optional in-person workshop during Istanbul Blockchain Week
- Submission opens: 2026-06-01 08:00
- Submission deadline shown by DoraHacks card: 2026-07-01 08:00
- Detail page timeline also lists qualification submission deadline as 2026-06-30; treat the earlier date as the internal build cutoff and use 2026-07-01 08:00 only as platform deadline grace.

## Prize Pool

- Total prize pool: USD 150,000
- Cash rewards: USD 30,000
- x402 ecosystem credits: USD 100,000
- In-kind rewards from joint sponsors: USD 20,000

## Track

There is one official track:

- Casper Innovation Track

Participants should build applications that use Casper infrastructure to unlock new financial use cases by combining:

- Artificial Intelligence, with strong emphasis on Agentic AI
- Decentralized Finance (DeFi)
- Real-World Assets (RWA)

The page especially encourages projects demonstrating Agentic AI solving real-world problems, while welcoming functional applications that contribute to the Casper ecosystem.

## Required Submission Artifacts

Each project must include:

1. Working prototype deployed on Casper Testnet, including an on-chain component that can generate transactions.
2. Open-source GitHub, GitLab, or Bitbucket repository with a README containing documentation and usage instructions.
3. Public demo video explaining the project, features, and walkthrough.

## Qualification Mechanism

- Community voting path: the top 3 projects by CSPR.fans app votes directly advance to the final round without additional judging.
- Builder merit path: all other projects must satisfy technical qualification standards, especially a Casper Testnet prototype with a transaction-generating on-chain component, to advance to professional jury evaluation.

## Eligibility and Conduct

- Individual developers and teams of any size are welcome.
- All code and content must be original and newly developed for the Buildathon.
- Projects must follow fair play, originality, anti-plagiarism principles, and the Casper Network code of conduct.

## Final Judging Criteria

- Technical execution: code quality, architecture, and implementation completeness
- Innovation and originality: novelty of approach, technology, and idea
- Use of AI / agentic systems: effective integration of AI agents and autonomous systems
- Real-world applicability: utility and relevance, especially in DeFi and RWA
- User experience and design: interface and interaction quality
- Working smart contracts: fully functional deployed Casper Testnet contracts
- Long-term launch plan: real project plan with social media support and practical deployment path
- Long-term impact potential: contribution to Casper ecosystem growth and adoption

## Developer Enablement

The workshop and ongoing support cover:

- Casper architecture
- Smart contract development with Odra
- CSPR tools and SDKs
- Best practices for scalable decentralized applications
- Agent workflows and solutions
- Casper AI Toolkit overview
- Using AI to build on-chain solutions
- Documentation, tutorials, ecosystem support, technical mentorship, marketing support, and possible Casper funding/incubation paths

## Build Direction Examples From DoraHacks

1. MCP-based autonomous yield-routing agent.
2. RWA oracle agent with verifiable on-chain identity.
3. Multi-agent DAO governance and execution system.
4. Knowledge-based AI-driven compliance and KYC workflow for DeFi/RWA.

This project initially explored direction 4, then after Manus review pivoted to direction 2: an RWA oracle agent with verifiable on-chain identity and reputation. The implementation still preserves privacy by keeping raw off-chain evidence out of contract state.
